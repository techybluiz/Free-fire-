# 🏝️ Mini Game de Sobrevivência em C — Free Fire Challenge

## 🎯 Objetivos do Trabalho
- Implementar listas lineares (vetores) e listas encadeadas.  
- Aplicar operações de inserção, remoção, percorrimento e buscas (sequencial e binária).  
- Comparar vetores e listas encadeadas em termos de eficiência.  
- Implementar métodos de ordenação como Selection Sort.  
- Organizar e otimizar dados para simular o inventário do jogador.  

---

## 🚀 Tecnologias Utilizadas
- Linguagem C  
- Estruturas de dados (vetor e lista encadeada)  
- Algoritmos de ordenação e busca
